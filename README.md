# DIY Emergency Power Box 🔋⚡

## 📌 About the Project

The DIY Emergency Power Box is a compact and portable emergency power source designed for use during power cuts.

It provides:
- 5V USB charging
- Adjustable DC voltage output
- Digital voltage monitoring
- LED lighting
- Rechargeable battery operation

## 🎯 Problem Statement

Frequent power cuts can affect charging of essential devices such as smartphones, routers and LED lights.

This project provides a compact and low-cost portable backup power solution for students and homes.

## 🔧 Components Used

- 2 × 18650 Li-ion Batteries
- 2-cell 18650 Battery Holder
- XL6009 Boost Converter
- USB Power Bank Module
- Mini Digital Voltmeter
- LED Strip
- ON/OFF Switch
- Acrylic Base

## ⚙️ Working

The 18650 batteries provide the input power.

The XL6009 boost converter increases the battery voltage and provides adjustable DC output.

The USB power module provides a 5V USB output.

The digital voltmeter displays the output voltage.
